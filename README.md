# velcro-community

Community-suggested update ideas for [velcro](https://github.com/riftaway7-code/velcro).

## How it works

1. Someone posts an idea in the Velcro suggestions channel.
2. `riftsclaude` talks it through with them one-on-one: what they actually want, edge cases, what would and wouldn't work, rough feasibility.
3. If the idea holds up, riftsclaude writes it here as `<discord-username>/<idea-slug>.md`.
4. Devs browse the folders and pull whatever they want to build into `velcro`.

## File layout

```
<username>/
  <idea-slug>.md
```

Each idea file has: the original ask, the refined proposal, feasibility notes (what works / what doesn't / open questions), and a status line.

Nothing here is a commitment to build. It's a triaged backlog.
