## Refined proposal
User wants Plague Inc: Evolved playable in the Velcro games hub.

## Feasibility — the problem
- Plague Inc: Evolved is a paid, commercial Steam title from Ndemic Creations.
- An HTML build of it is an unauthorized rip. There is no official free/web
  version.
- Hosting it on Velcro is a DMCA / takedown risk. A claim against a ripped
  commercial game can hit the whole site's host, not just the one file.

## Safer alternatives if the genre is what's wanted
- Link out to the game elsewhere instead of hosting the file.
- Add a genuinely free browser pandemic/strategy sim in the same vein (there
  are open-source and freeware "infect the world" clones).
- Poll the community for free games they actually want, add those in bulk.

## Recommendation
Do not host the ripped build. If there's real demand for this specific game,
decide as a team whether to link-out or substitute. Otherwise close.
